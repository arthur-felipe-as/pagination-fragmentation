# Simulador de Paginação e Fragmentação - SO

Simulador para análise e visualização dos conceitos de **paginação** e **fragmentação interna/externa** na gestão de memória de Sistemas Operacionais.

---

### Pré-requisitos
* Compilador **GCC / Clang** (para C/C++) ou ambiente **Python/Node.js** (de acordo com a linguagem utilizada no repositório).

## Como Executar

   ```bash
   # P/ compilar
    # Caso GCC

    g++ pag_frag.cpp -o pag_frag

    # Caso Clang

    clang++ pag_frag.cpp -o pag_frag

   # P/ executar

    ./pag_frag
